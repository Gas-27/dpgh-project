## HOW THE MATCHING WORKS

### Level 1: Exact Match
If user types: "hello"
Matches: "hello" in questions array
Returns: Greeting response

### Level 2: Keyword Matching
If user types: "How do I buy data?"
Matches: "buy data" is in questions array
Returns: Data purchase guide

### Level 3: Partial Word Matching
If user types: "min withdrawal?"
Matches: Words "min" and "withdraw" in questions
Returns: Minimum withdrawal information

## HOW TO ADD NEW QUESTIONS

To add a new Q&A to the knowledge base:

1. Open: `/src/data/chatbot-knowledge-base.ts`
2. Find: `export const CHATBOT_KNOWLEDGE_BASE: KnowledgeEntry[] = [`
3. Add new entry:
```typescript
{
  questions: ["keyword1", "keyword2", "keyword3"],
  answer: "Your detailed answer here",
  category: "category_name"
}
```
4. Save file
5. Deploy
6. Chatbot immediately knows the new answer!
