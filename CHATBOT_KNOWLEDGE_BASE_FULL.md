3. View all available sizes and current prices

### Key Information
- **Prices:** Vary by network and package size (check Packages page for exact pricing)
- **Delivery:** Instant - within 30 seconds after payment
- **Availability:** 24/7
- **How to Buy:** 
  1. Go to Packages page
  2. Choose network & size
  3. Pay (Mobile Money, Bank, or Card)
  4. Get data instantly

### Troubleshooting
- **Package Offline?** - Temporary maintenance or network issues. Try again in few minutes.
- **Data Not Received?** - Check balance, restart phone, wait 5-10 minutes. Contact support if not received within 15 minutes.
- **Data Validity:** Depends on package type (daily = 24h, weekly = 7d, monthly = 30d)

## 4. AFA PROGRAM (Agricultural Financing)

### What is AFA?
**AFA = Agricultural Financing and Assurance**

Special government-backed program for farmers:
- Subsidized data bundles
- Access to farming knowledge & resources
- Expert guidance
- Support from MTN network
- Community of farmers

### Registration Process
1. Click "AFA Bundles" button
2. Click "Register for AFA"
3. Fill form with:
   - Full name
   - Phone number
   - Region/Town
   - Crop type
   - Other farming details
4. Pay GH₵15 (one-time registration fee)
5. **Wait 24-72 hours for MTN approval**
6. Receive SMS confirmation
7. Activate your AFA bundles

### Approval Timeline
- **Registration:** Instant (after payment)
- **MTN Approval:** **24-72 HOURS** (usually within 48 hours)
- **Data Activation:** Immediate after approval
- Keep phone available during approval period
- Check SMS regularly for approval notification

### AFA Registration Fee
- **Cost:** GH₵15 (one-time only)
- **Includes:** Full registration, MTN verification, membership, exclusive bundle access
- **Payment Methods:** Mobile Money, Bank Transfer, Card, Wallet

### Eligibility Requirements
✅ Must be:
- 18+ years old
- Have valid phone number
- Actively involved in farming
- Ghana-based
- Provide accurate information

### Benefits
- Affordable data for agricultural knowledge
- Subsidized bundle pricing
- Weather updates & farming techniques
- Market prices & best practices
- Connect with other farmers
- Government & MTN support
- Priority customer support

## 16. HOW THE CHATBOT WORKS

### Matching Algorithm
The chatbot uses intelligent Q&A matching with three levels:

1. **Exact Match** - User question exactly matches a knowledge base question
2. **Keyword Match** - User question contains keywords from knowledge base
3. **Fuzzy Match** - Partial word matches (3+ character words)

### Example Questions the Chatbot Can Answer
- "How do I buy data?"
- "What's the price?"
- "How long delivery?"
- "MTN packages?"
- "AFA registration how?"
- "Agent commission?"

## HOW TO UPDATE THIS KNOWLEDGE BASE

The knowledge base is stored in: `/src/data/chatbot-knowledge-base.ts`

To add more information:
1. Add new entry to `CHATBOT_KNOWLEDGE_BASE` array
2. Include `questions` array with keywords that trigger this entry
3. Include `answer` string with detailed response
4. Include `category` for organization
5. Add question to `FREQUENT_QUESTIONS` array if it's a common question
6. Save and deploy - chatbot immediately has new knowledge!

### Example Entry
```typescript
{
  questions: ["your keyword", "another keyword"],
  answer: "Your detailed answer here",
  category: "category_name"
}
```
